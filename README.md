# Smart Resume Builder & Management System

## Project Overview

The Smart Resume Builder & Management System is a desktop application developed using Python. It enables users to create, edit, view, manage, and generate professional resumes in PDF format through a modern graphical user interface.

The application stores resume information in an SQLite database and allows users to update or retrieve their records whenever required.

---

## Features

- User-friendly Dashboard
- Create Resume
- View Resume
- Edit Resume
- Store Resume in SQLite Database
- Generate Professional PDF Resume
- Settings Module
- Modern GUI using CustomTkinter

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Smart-Resume-Builder.git
```

Move into the project folder

```bash
cd Smart-Resume-Builder
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python dashboard.py
```
